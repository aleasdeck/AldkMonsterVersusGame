# Нарисованные спрайты

PNG отсюда подменяет процедурный спрайт везде, где боец показывается: бой, блок героя,
выбор героя, лист персонажа, бестиарий, итоги. Механика — `src/ui/art.ts`.

- **Имя файла — id бойца:** `warrior.png`, `mage.png`, `assassin.png`, `paladin.png`,
  `berserk.png`, `archer.png`; враги — по id из `src/data/enemies.ts` (`wolf.png`, `troll.png`, …).
- **Формат:** PNG, прозрачный фон, 128×128.
- **Кадр:** боец стоит на нижней кромке кадра и занимает его по высоте целиком. В бою спрайт
  прижимается низом к земле, поэтому лишние пустые пиксели под ногами поднимут его над остальными.
- Правки в `src/data/*.ts` не нужны: файла нет — рисуется процедурный спрайт, файл есть — берётся он.

В бою герой показывается в 128 px (1:1), враги — от 70 до 120 px по рангу. Всё, что мельче
исходника, `spriteImg` сглаживает: чёткое уменьшение выедает пиксели (тонкий клинок исчезает целиком).
