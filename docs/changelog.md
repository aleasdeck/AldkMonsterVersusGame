# Чейнджлог для Telegram

Публикация — это merge в `main`: после него GitHub Pages сам выкладывает игру. Перед каждой публикацией Claude пишет пост по шаблону ниже и показывает его в ответе копируемым блоком (в тройных обратных кавычках), чтобы пост можно было вставить в Telegram одним сообщением. Тем же коммитом пост добавляется в раздел «Опубликовано» этого файла, сверху. Что вошло в версию, видно по абзацам GDD §13 со времени прошлого поста.

## Правила

1. **Первая строка — версия** в формате `v50.0`: `GAME_VERSION` из `src/engine/types.ts` без ведущего `0.` (`0.50.0` → `v50.0`, `0.40.5` → `v40.5`).
2. **Вторая строка — суть версии** в двух–пяти словах, без точки: «Интерфейс стал легче».
3. После пустой строки идут **блоки** — только те, где есть изменения, всегда в этом порядке и с этими эмодзи:

   | Эмодзи | Блок | Что сюда |
   |---|---|---|
   | ⚔️ | Персонаж и бой | герои, выбор героя, навыки и черты, мастерство, правила боя, плитки приёмов, лист «Персонаж» |
   | 🎒 | Снаряжение | оружие, броня, артефакты, зелья, карточки, описания, лут |
   | 👾 | Враги и локации | враги, боссы, локации, испытания |
   | 🧭 | Забег | карта, события, награды, торговец, золото |
   | 🖥️ | Интерфейс | экраны, подсказки, управление — что не легло в блоки выше |
   | ⚖️ | Баланс | изменения чисел: было → стало |
   | 🛠️ | Исправления | ошибки и неточности в текстах |

4. **Пункт** начинается с `•` и пробела — всегда этим символом. Он не спорит с тире внутри фраз и одинаково выглядит в любом клиенте Telegram. Пункт — одна-две короткие фразы с точкой в конце, в блоке не больше пяти пунктов.
5. Пишем для игрока: что он увидит и почувствует. Без имён файлов, функций и внутренних терминов. Числа — «было → стало»: «Урон 4–6 → 5–7».
6. В конце — две строки: «Играть: https://aleasdeck.github.io/AldkMonsterVersusGame/» и строка про сохранение: «Сохранённый забег продолжится.» или, если поднят `SAVE_VERSION`, «Сохранённый забег сбросится: новая версия сохранения.»
7. Жирным — версия и заголовки блоков, звёздочками `**…**`: Telegram делает их жирными при отправке. Весь пост — одно сообщение, не длиннее 4096 знаков, лучше до 2000.
8. Публикация без изменений для игрока (документы, тесты, инструменты) поста не требует.
