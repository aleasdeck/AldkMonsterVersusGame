# ADR 0004. Дары и испытания перед локацией

- **Дата:** 2026-09-23 (v0.41.16)
- **Статус:** принято частично (2026-09-23): пока только тематические испытания, по три на локацию, перед локацией показываются два случайных, игрок выбирает одно обязательно. Дары отложены. Список из 18 испытаний и место в порядке работ — [план реворка](../plan-reworka.md), §4 и §6.
- **Задача:** локации сейчас отличаются врагами и фоном, но играются одинаково. Пользователь предложил выбор перед каждой локацией по образцу Нео из Slay the Spire (в начале забега выбираешь один «прикол» из нескольких), только у нас — выбор из бафов или выбор из дебафов. Цель — уникальность каждой локации и лишнее решение, которое меняет план на ближайшие десять клеток.

## Решение (2026-09-23)

Из вариантов ниже взята половина C: осложнение у локации тематическое, но выбирается одно из двух случайных, без награды. Выбор значим, потому что зависит от сборки: какое испытание меньше бьёт по ней. Дары и вариант A («испытание за лишний дар») остаются на будущее — ниже как было предложено.

## Референсы

- **Slay the Spire, Нео.** Один раз в начале забега, 4 варианта разной силы; сильные — с ценой («−макс HP, получи редкую реликвию»). Короткий, понятный выбор, который задаёт тон забегу.
- **Hades, Пакт наказания.** Игрок сам берёт осложнения за лучшую награду. Работает, потому что награда видна и осложнение можно планировать.
- **Monster Train, испытания кланов.** Осложнение на весь забег, награда — сразу.

Урок: **осложнение интересно, только если его берут добровольно за видимую награду** и если под него можно перестроить игру. Случайный дебаф без выбора — просто налог.

## Когда и как долго

- Экран «Порог» перед каждой из трёх локаций: при старте забега и сразу после босса (после лечения `BOSS_HEAL_PCT`, в `advanceRoom`, где растёт `locationIndex`).
- Действие — **до конца этой локации** (10 клеток), потом снимается. Это и даёт уникальность: у каждой локации забега свой характер, а не накопленная пачка бафов. Исключение — разовые дары (золото, артефакт, кузнец), они срабатывают сразу.
- Это не мета-прогрессия: дары живут внутри забега, профиль не трогают.

## Варианты

- **A. «Дар или испытание» (рекомендуется).** На экране две колонки по три карточки. Берёшь **один дар** — или **одно испытание**, и тогда к нему **два дара на выбор из трёх** (или один дар посильнее). Решение настоящее: осторожно, или рискнуть ради большего. Прямо ложится на просьбу пользователя.
- **B. Пары «дар + цена», как у Нео.** 3–4 карточки: слабый дар без цены, средний и сильный — со своим осложнением. Проще экран, но выбор уже.
- **C. Дар на выбор + фиксированное осложнение локации.** У каждой из шести локаций своё постоянное свойство (Пещеры огня жгут, Болота травят), игрок выбирает только дар. Больше уникальности, меньше решения.

Хорошо сочетаются A и C: у каждой локации **своё тематическое испытание**, которое выпадает только в ней, плюс общие.

## Пул

Числа — первый проход.

### Дары

| Дар | Действие | Движок |
|---|---|---|
| Знамение архетипа | в этой локации артефакты выбранного архетипа (Кровь, Огонь…, ADR 0003) выпадают ×3 | вес в `artifactWeight`, нужны метки |
| Точильный камень | +1 к мин. и макс. урону оружия | статы |
| Запас сил | +1 STA в первый ход каждого боя | `firstTurnSta` |
| Родник | +3 HP после каждого боя | хук в `finishBattle` |
| Зоркость | награды за бой — 4 карточки вместо 3 | `rollRewards` |
| Тихий шаг | первая атака врага в каждом бою промахивается | `dodgeStart` |
| Кошель | +40 золота сразу | разовый |
| Реликварий | сразу артефакт тира акта на выбор из 3 | разовый, экран награды |
| Горн | сразу поднять тир оружия или брони | разовый, как кузнец |

### Общие испытания

| Испытание | Действие |
|---|---|
| Кровавая луна | враги наносят +15 % урона |
| Толстокожие | враги +20 % HP (осторожно: HP врагов +40 % давали паты бота) |
| Туман | намерения врагов скрыты (чистый UI) |
| Истощение | −1 STA в первый ход боя |
| Засада | в каждом бою +1 рядовой враг из локации (до `MAX_ENEMIES`) |
| Скупость | золото с боёв −50 % |
| Хрупкость | «Защититься» даёт на 30 % меньше блока |

### Тематические испытания локаций (выпадают только в своей)

| Локация | Испытание | Действие |
|---|---|---|
| Лес | Стая | в каждом бою к врагам присоединяется волк |
| Болота | Трясина | герой начинает бой с Ядом 1 на 3 хода |
| Склеп | Неупокоенные | первый убитый в бою враг встаёт с половиной HP |
| Осквернённый улей | Рой | в начале боя каждому врагу Шипы 1 |
| Пещеры огня | Зной | Горение на герое тикает на 1 сильнее |
| Пиратский корабль | Качка | первый ход боя — −1 STA и −1 MP |

Тематические испытания хорошо дружат с ADR 0003: Зной бьёт по всем, но «Жаропрочность» его отменяет, Рой наказывает серию ударов — есть повод перестроиться.

## Устройство (набросок)

- `RunState.omen: { boons: string[]; trials: string[] } | null` — действующее в текущей локации; фаза `threshold` (или событие вида `threshold` в фазе `event`). Меняется форма `RunState` — поднять `SAVE_VERSION`.
- Данные — `src/data/omens.ts`: `BoonDef` / `TrialDef` с `mods` (статы героя, как у пассивок), `enemy` (множители HP/урона, статусы на старте боя), `loot` (веса, число карточек, золото), `once` (разовое действие). Всё случайное — через `run.rng`.
- UI: экран «Порог» в каркасе `runFrame`, карточки дара и испытания; действующее — чип в топбаре с подсказкой.
- Статистика: колонки `boons` / `trials` в `RunReport`.
- Бот: выбирать дар по ценности (как награду), испытание — только если сумма даров перекрывает (первый проход — никогда, чтобы SIM мерил дары отдельно).
- Отладка: `&omen=boon:grindstone,trial:fog`.

## Открытые вопросы

- Вариант A, B или C (или A + C).
- Дар и испытание — до конца локации или до конца забега (второе сильнее и ближе к Нео, но размывает уникальность локации).
- Нужен ли «Порог» перед первой локацией, или первый забега — без него, чтобы не удлинять вход.
- Делать до пилота ADR 0003 или после: «Знамение архетипа» требует меток на артефактах.
