# Пиксельная лепка: как сделать врага

Лепка — враг, нарисованный кодом: модель собирает тело из фигур, движок освещает его и раскладывает в пиксели, игра получает лист из трёх клипов — покой, удар и урон. Так с v0.52 нарисованы все враги Леса и оба гнома-вора, с v0.53 — все враги Болот; образцы приёмов — `src/ui/mobs/forest.ts` и `src/ui/mobs/swamp.ts`. Этот документ — порядок работы, справочник и ловушки для следующей локации.

Лепка — для врагов без рисованного листа. Скелеты и некромант нарисованы листами (`enemySprite.ts`, `docs/art.md`), лепки у них быть не должно: тест это запрещает. Локация переходит на лепку целиком: как только у одного её врага появилась модель, тест требует модель у всех остальных (кроме рисованных).

Стиль общий и выбран пользователем — «пиксель фона» (`MOB_STYLE` в `styles.ts`: пиксель рисунка — 2 px кадра боя, пять тонов на материал, выборочный контур, контровой свет). Новая локация стиль не меняет: правка стиля или движка перерисует всех врагов сразу.

## Где что лежит

| Файл | Что там |
| --- | --- |
| `src/ui/mobs/pixel.ts` | движок без DOM: фигуры, свет, рамп цвета, контур, позы, кривые клипов, `renderSheet` |
| `src/ui/mobs/styles.ts` | `MOB_STYLE` — один стиль на всех: пиксель, тона, кадры и частота клипов |
| `src/ui/mobs/<локация>.ts` | модели локации и её реестр `<ЛОКАЦИЯ>_MODELS` (`forest.ts` — `FOREST_MODELS`, `swamp.ts` — `SWAMP_MODELS`) |
| `src/ui/mobs/index.ts` | общий реестр `MOB_MODELS` и всё игровое: запекание листа, прогрев, клипы в бою |
| `tests/mobs.test.ts` | проверки всех моделей реестра; новую локацию подхватывают сами |
| `tools/mob-sheet.mjs` | PNG всех кадров модели и сводка с предупреждениями — без браузера |
| `tools/mob-preview.html` | живой обзор всех клипов на полу локации (dev-сервер) |

## Порядок работы

1. **Собрать врагов локации.** Из `enemies.ts` — имя, ранг, роль, приёмы и `sprite` (палитра прежнего спрайта). Из `characterSizes.ts` — рост `ENEMY_BODY_HEIGHT`. Посмотреть фон локации (`src/assets/backgrounds/<лок>-wide.png`) и её свет (`TINTS` в `tint.ts`).
2. **Слепить покой** всех врагов (шаги 1–3 ниже), проверить листами и обзором.
3. **Добавить удар и урон** (шаги 4–5).
4. **Подключить** в `MOB_MODELS` и проверить в бою (шаги 6–7).
5. **Показать пользователю** страницу-обзор: сцена боя со всеми встречами локации и галерея врагов в трёх клипах. Образец — страница «Лепка лесных мобов» (Artifact, v0.52): один HTML, в нём esbuild-бандл `pixel.ts` + `styles.ts` + моделей, данные врагов (имя, ранг, приёмы числами первого акта через `describeAction`, как в бестиарии) и фон локации в data URI; ~0.8 МБ. Правки — по отзыву.
6. **Документы и публикация** (шаг 8).

Для первой локации пользователь выбирал из вариантов; для следующих стиль уже решён, варианты нужны, только если сам враг спорный (например, как читать призрака или слизь).

## Шаг 1. Модель

```ts
import type { Mat, Model, Painter } from './pixel';

// Материалы врага: средний тон, фактура, блеск. Рамп из пяти тонов движок строит сам.
const GHOUL = {
  skin: { base: '#7d8a6a', shag: 0, tex: { kind: 'noise', scale: 3, amp: 0.14 } } as Mat,
  rag: { base: '#4a3f36', shag: 0.2, tex: { kind: 'stripes', scale: 2.5, amp: 0.12, angle: 1.4 } } as Mat,
  claw: { base: '#d8d0bc', dither: 0 } as Mat,
};

export const ghoul: Model = {
  id: 'ghoul',
  w: 72, // рамка в пикселях кадра боя
  h: 96,
  ground: 92, // линия земли: на ней стоят ступни
  // pad: 30, — поле для клипов, если замах выходит за рамку дальше 22 единиц (шаг 4)
  draw(p: Painter) {
    const { wind, strike } = p.attack();
    const hurt = p.hurt();
    p.pose({ dx: -9 * strike + 3 * wind + 4 * hurt, rot: -0.06 * strike + 0.05 * wind + 0.08 * hurt, px: 36, py: 92 }, () => {
      p.shadow(36, 22, 3);
      // … дальние конечности, тело, ближние конечности, голова, декали …
    });
  },
};

export const CRYPT_MODELS: Record<string, Model> = { ghoul };
```

Если рост мимо таблицы нужен по замыслу, модель говорит это сама: `ownHeight: 'причина'` (крыса длинная и низкая) — тест и инструменты его не сверяют; `flies: true` — парит над полом, тест не ищет ступни на земле (мышь).

Регистрация — импорт и одна строка в `index.ts`: `export const MOB_MODELS = { ...FOREST_MODELS, ...SWAMP_MODELS, ...CRYPT_MODELS };`. Дальше игра всё делает сама: бой, бестиарий, союзник, аура босса, прогрев листов.

Координаты — в пикселях кадра боя: `x` вправо, `y` вниз, существо смотрит **влево**, на героя. Рамка `w`×`h` — место тела; рост (от макушки до `ground`) подгоняется под `ENEMY_BODY_HEIGHT` с точностью ±12 % — масштабом `scaleModel(model, s)`, а не переписыванием координат (так сделаны кабан ×1.12, Тролль ×156/144, вещекрад ×64/59). Разновидность того же существа — `p.scope(s, ox, oy, fn)` внутри своей модели: Вожак стаи — это волк ×5/3 со своими материалами.

## Шаг 2. Тело

**Порядок рисования — это порядок слоёв:** поздняя фигура накрывает раннюю. Обычный порядок: тень → дальние конечности → хвост → туловище → ближние конечности → шея и голова → лицо и оружие → декали.

**Части.** Фигуры с одинаковым `part` сливаются в одну поверхность мягким максимумом высот — грудь, живот и круп волка светятся как одно тело. Между разными частями движок рисует линию у той, что позади (лапа поверх туловища, челюсть под головой). Без `part` фигура идёт в `body`. Обычные имена: `far`, `near`, `head`, `jaw`, `ear`, `tail`, `farArm`, `weapon`.

| Опция фигуры | Зачем |
| --- | --- |
| `part` | часть тела (см. выше) |
| `tone` | сдвиг света −1…1: дальние лапы и брюхо −0.1…−0.15 |
| `paint: true` | только перекрасить свою часть под фигурой: чепрак, светлое брюхо, пятна — форма остаётся от тела |
| `lift` | поднять купол над своей частью: мышца, щека, нос не тонут в туловище |
| `flat` | 0 — шар, 1 — плоский лист: ткань, пластины |
| `rot` | поворот эллипса вместе с фактурой |
| `bevel` | фаска полигона: светлый верхний край |
| `noLine` | не давать соседям линию об эту фигуру |

**Фигуры:** `ellipse(cx, cy, rx, ry, mat, opts)` — купол; `limb(x1, y1, r1, x2, y2, r2, mat, opts)` — сужающаяся капсула (лапа, рука, шея); `chain([[x, y, r], …], mat, opts)` — цепочка капсул (хвост, лапы паука); `poly([x0, y0, x1, y1, …], mat, opts)` — многоугольник (одежда, уши, клыки, клинок); `erase(cx, cy, rx, ry)` — вырез (просвет, пасть).

**Декали** — поверх готового рисунка, пикселями: `eye(x, y, r, color, { closed, glint, lid, pupil })` — глаз с бликом (`closed` 1 — веко, 0.5 — прищур); `px`, `block`, `line` (линия в пиксель: тетива, усы, рот), `disc`, `glow(x, y, r, color, alpha)` — свечение в пустых клетках; `shadow(cx, rx, ry, alpha)` — тень на полу.

**Материал** `Mat`: `base` — средний тон (не самый светлый: рамп строится вверх и вниз от него), `tex` — фактура (`fur`, `noise`, `spots`, `stripes`, `bark`; `scale`, `amp`, `angle`, `stretch`), `shag` — рваный край 0.15–0.25 у шерсти и лохмотьев, `shine` — блик металла, мокрого носа, `glow` — светится сам (кристалл, пламя), `dither: 0` — без дизеринга (глаза, металл, зубы), `noOutline` — без контура (нити, дым), `ramp` — свой рамп вместо построенного.

**Правила вида** (то, что держит врагов одним набором):
- Палитра продолжает прежний спрайт (`sprite` в `enemies.ts`): игрок должен узнать врага.
- Одна яркая черта на врага: пасть и уши волка, посох с кристаллом шамана, тесак Головореза.
- Самое яркое пятно головы — глаз; чистые чёрный и белый — только в бликах и зубах.
- При пикселе 2 деталь мельче 2 единиц пропадает: тонкое — линией в пиксель (`line`) или `chain` без контура.
- Смотреть в масштабе ×1 на полу своей локации: там решается, читается ли силуэт.

## Шаг 3. Покой

Цикл 3 с (24 кадра по 8 в секунду), фаза `p.t` 0…1:

- `p.wave(k, phase)` — синус, `k` периодов за цикл (дыхание 3–4, хвост 1);
- `p.bob(amp, k, phase)` — смещение целыми пикселями, не меньше пикселя;
- `p.snap(v)` — любое смещение, прижатое к сетке: без него контур дрожит;
- `p.blink(at, len)` — короткое событие цикла: моргнуть, дёрнуть ухом.

Движения — на 1–2 пикселя: дыхание, одно событие за цикл, что-то своё (хвост, посох, монета). `Math.random` нельзя: рисунок обязан быть одинаковым от запуска к запуску (тест).

Первый кадр покоя (`t = 0`) — поза, из которой клипы начинаются и в которую возвращаются. Всё, что бывает только в покое (блик по кромке тесака, капля слюны), рисовать при `p.clip === 'idle'` и так, чтобы при `t = 0` его не было: иначе на стыке клипа с покоем скачок (тест «клип кончается позой покоя»).

## Шаг 4. Удар

```ts
const { wind, strike } = p.attack(); // вне клипа удара — нули: тот же код рисует покой и урон
```

| Кадр (из 8) | 1 | 2 | 3 | 4 | 5 — контакт | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| мс от начала | 0 | 83 | 167 | 250 | 333 | 417 | 500 | 583 |
| `wind` (замах) | 0.35 | 1 | 1 | 0.16 | 0 | 0 | 0 | 0 |
| `strike` (выпад) | 0 | 0 | 0 | 0.34 | 1 | 0.71 | 0.31 | 0 |

- **Кадр контакта — пятый** (333 мс): к нему игра приурочивает снаряд, цифру урона и реакцию героя. В нём зубы, клинок или снаряд — в самой дальней точке к герою.
- **Тело целиком** — `p.pose({ dx, dy, rot, px, py }, fn)`: наклон `rot` вокруг опоры (px, py) — ступни или бёдра, минус — к герою; сдвиг `dx`/`dy` целыми пикселями, минус `dx` — к герою. Тень рисовать внутри позы и без `y`: она сдвинется с телом, но останется на полу.
- **Часть тела** — вложенная `p.pose` вокруг сустава: голова вокруг шеи, рука вокруг плеча.
- **Оружие по дуге** — угол по ключам через `keys(k, p.u)` (`arc(p, k)` из `pixel.ts`: вне удара — 0). Рубка через голову: ключи идут от покоя назад-вверх и вперёд-вниз, последний ключ −2π — полный оборот, то есть снова покой (`CHOP`, `SMASH`).
- **Кисть и предмет** — точка «покой + (замах − покой)·wind + (удар − покой)·strike» (`mixPt` из `pixel.ts`): так гномы тянутся за кошельком, а пиявка, шеи Гидры и хлыст Топяного ужаса гнут хребет — `mixPt` для каждой его точки.
- **Рука с локтем** — два угла по ключам (плечо и предплечье, `SWIPE_*` у Кикиморы, `GRAB_*` у Утопленника) или локоть от плеча к кисти, которая держит древко (`joint` в `swamp.ts`, трезубец Тритона).
- **Часть отстаёт от тела** — `p.attack(lag)`: те же кривые, сжатые в остаток клипа; головы Гидры бьют по очереди, но в покой приходят одним кадром.
- **Поле кадра.** Лист модели — рамка с полем `pad` (22 единицы по умолчанию) слева, справа и сверху. Выпад или замах дальше поля срежется о край листа: нос, кончик тесака, стрела. Тест «не упираются в край листа» и `tools/mob-sheet.mjs` это ловят; лечится `pad` в модели (Головорез 50, Тролль 50 после масштаба, Вожак 36, шаман 30, лучник 26).

## Шаг 5. Урон

```ts
const hurt = p.hurt(); // по кадрам: 1, 0.85, 0.45, 0.15, 0
```

5 кадров по 12 в секунду (0.42 с). Белую вспышку двух первых кадров добавляет движок, модели её не рисуют. От модели нужна отдача **от героя**: `dx` +3…+7, `rot` +0.04…+0.08 для тела; голова запрокидывается (+0.1…+0.3 во вложенной позе), глаза закрыты (`closed: hurt > 0.4 ? 1 : p.blink(…)`), уши прижаты, пасть открыта, щит взлетает. Ступни остаются на полу.

## Шаг 6. Подключение

- Модели локации — в `MOB_MODELS` (`index.ts`); больше в игре ничего менять не нужно.
- Клип удара играют приёмы с эффектом `attack`, `stealGold` или `stealArtifact`; вой, блок, лечение и призыв остаются общим наскоком. Приём из нескольких ударов («3×2») повторяет удар на каждое попадание с кадра перед контактом — модели для этого ничего не нужно.
- Урон по врагу играет клип урона вместо тряски.
- Враг, которого герой призывает союзником, получает тот же лист, развёрнутый CSS к врагам.
- Рост в бою и в бестиарии задаёт модель (`mobMetrics`), таблица `ENEMY_BODY_HEIGHT` остаётся ориентиром и проверкой.

## Шаг 7. Проверка

1. `npx vitest run tests/mobs.test.ts` — модель у каждого врага локации и ни у одного рисованного, ступни на земле (кроме `flies`), рост ±12 % от таблицы (кроме `ownHeight`), число кадров клипов, стык клипа с покоем, заметная поза в кадре контакта, вспышка урона, край листа, детерминизм, живой покой (кадры цикла различаются).
2. `node tools/mob-sheet.mjs <локация | id,id>` — лист каждой модели в PNG (`mob-preview/`, ×3; `--zoom`, `--out`): ряд покоя, ряд удара с подчёркнутым кадром контакта, ряд урона. В консоли — рост против таблицы, ширина, время отрисовки и предупреждения. PNG смотреть покадрово: так видны дрожь, скачки и обрезанные края.
3. `npm run dev` → `http://localhost:5173/tools/mob-preview.html?loc=<локация>` — все клипы вживую на полу локации с тонировкой боя; `&speed=0.25` — замедлить, клик по клетке — повторить клип. Правка модели перезагружает страницу.
4. Бой: `?hero=warrior&locs=<локация>,forest,ship&foes=a,b,c&enter=1` — удар по врагу показывает урон, «Конец хода» — удары; союзник — `?hero=mage&locs=forest,crypt,ship&art=wolf_whistle&use=wolf_whistle&enter=1`; бестиарий — `?screen=bestiary&loc=<локация>`.
5. Съёмка боя в Playwright: живую последовательность снимать по таймеру. Не замораживать анимации (`getAnimations().pause()`) посреди хода врагов: `render()` в это время создаёт новые узлы, и на кадре выходят две фигуры.

## Приёмка

- [ ] Силуэт читается в ×1 на полу своей локации, главная черта врага видна.
- [ ] Палитра продолжает прежний спрайт и не выбивается из локации: элита и босс не светлее и не насыщеннее рядовых (кроме тех, кто светится); свет сверху слева, тени холоднее, свет теплее.
- [ ] Покой: дыхание и одно событие за цикл, без дрожи; цикл замыкается без скачка.
- [ ] Удар: замах виден в кадрах 2–3, в пятом — самая дальняя точка к герою, потом возврат в покой; ничего не срезано краем листа.
- [ ] Урон: вспышка и отдача от героя, глаза закрыты или рот открыт, возврат в покой.
- [ ] Рост ±12 % от таблицы (или `ownHeight` с причиной), ступни на полу (или `flies`), тень на земле.
- [ ] Тесты зелёные, `tools/mob-sheet.mjs` без предупреждений.

## Ловушки

- **Стык с покоем.** Деталь только для покоя, видимая при `t = 0`, ломает переход клипа в покой. Блик тесака Головореза начинается с `t > 0.03`.
- **Край листа.** Выпад дальше `pad` молча срезает нос или клинок в игре. Ловит тест; в v0.52.0 так ушли Вожак, Головорез, шаман и лучник — исправлено в v0.52.1.
- **Тонкое на крупном пикселе.** Лапы паука кашей из контуров — рисовать светлыми линиями без контура (`noOutline`) и тоньше.
- **Лицо под шляпой.** Поля шляпы и капюшон закрывают глаза при ×1 — приподнять и проверить на полу локации.
- **Шов между эллипсами** одной формы — разные `part`; одно тело — одна часть.
- **Яркая палитра на крупной фигуре.** Цвета прежнего спрайта, терпимые на маленьком блобе, на элите в полкадра бросаются в глаза: в v0.53 Гидра (изумрудная, со светлыми гребнями) и Мать жаб (светлее и ярче своих жаб) выбились из Болот, их пришлось приглушить до оливы набора. Крупного врага сверять с рядовыми рядом, на полу локации с тонировкой (`tools/mob-preview.html?loc=<локация>`).
- **Серое синеет.** Почти нейтральный серый уходит в тенях в синеву — это по замыслу для стали и пепла; бурой шерсти дать `base` с заметным оттенком.
- **Пряди** (`shag`) выше 0.25 на лапах похожи на траву.
- **Движок и стиль общие.** Правка `pixel.ts` или `MOB_STYLE` меняет всех врагов — после неё `node tools/mob-sheet.mjs all` и глазами по всем локациям.
- **Цена отрисовки** — 20–120 мс на модель (все 37 кадров), у крупных Болот до ~200 мс (Гидра, Топяной ужас), один раз за сессию: листы локации рисуются впрок, пока игрок на карте (`warmMobs`). Сотни мелких фигур в цикле делают модель тяжёлой — лучше меньше крупных; каждая `part` — ещё три буфера размером с кадр.
- **Мелкое тело — одна часть.** У комара грудь, голова и брюшко в разных `part` дают линии между частями, и они съедают весь цвет тела в 3–4 пикселя. Одно существо — одна часть (`gnat${i}`).
- **Полупрозрачные декали не складываются.** Вторая полупрозрачная декаль поверх первой делает пиксель непрозрачным. Прозрачную заливку (крыло комара) рисовать по клеткам — каждая клетка ровно одной декалью (`wing` в `swamp.ts`), при чётном `pad` и чётных сдвигах, чтобы сетка не сбивалась.
- **Масштаб разновидности.** У модели в `scope` всё, что ниже земли, растёт вместе с ней: у жабы стопа на полпикселя ниже пола проходит, у Матери жаб (×2,36) — уже нет. Нижний край ступней держать ровно на `ground`.
- **Отставание части.** Сдвиг хода клипа `p.u − lag` без сжатия не доводит часть до покоя к последнему кадру — тест стыка падает. Брать `p.attack(lag)`.
